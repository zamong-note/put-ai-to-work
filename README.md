# 장중대리

> 직장인이 정한 매매 규칙을 대신 지키고, 고른 위험 단계에 맞춰 자동으로 투자해 주는 에이전트
> **한국투자증권 모의투자 계좌 전용** · 투자 조언이 아니며 실제 돈으로 운용하지 않습니다.

Claude Agent SDK · 한국투자증권 KIS Open API(모의투자) · 텔레그램 봇 · Google Sheets · SQLite · 로컬 웹 대시보드

---

## 누구를 위한 에이전트인가

**34세 회사원, 국내 주식에 1,500만 원 정도 투자하는 개인투자자.**
9시부터 6시까지 회의와 업무로 바빠서, 장중에 틈틈이 MTS를 열어 보지만 원하던 가격을 자주 놓칩니다.
일부 종목은 직접 공부해서 고르지만, 공부할 시간이 없는 나머지 돈은 예금에 그냥 두고 있습니다.

| 지금 (비포) | 장중대리 사용 후 (애프터) |
|---|---|
| 퇴근 후 관심 종목·목표가를 메모장에 적음 | 텔레그램에 규칙을 말로 적어 한 번 등록 |
| 장중 하루 10~20번 MTS 시세 확인, 직접 주문 | 장중에는 체결 알림만 받음 |
| 놓치거나 충동 매매 | 등록한 규칙대로만 주문하고, 모든 주문에 근거를 남김 |
| 남는 돈은 예금에 방치 | 위험 단계(1~5)만 고르면 정해진 전략대로 운용·리밸런싱 |
| 주말에 수익률을 엑셀에 옮겨 적음 | 매매일지·일일 요약이 CSV/Google Sheets에 자동 기록, 일간·주간·월간 PDF 보고서가 메일로 옴 |

## 어떤 업무를 대신하나

### 1. 규칙 매매: 내가 고른 종목
```
나: SK하이닉스 수익률 15% 넘으면 절반 팔고, 산 가격보다 7% 떨어지면 전부 팔아 줘

장중대리: [규칙 등록 확인]
 1) SK하이닉스 · 수익률 ≥ +15% → 보유의 50% 매도 (예상 10주) · 최대 1회
 2) SK하이닉스 · 수익률 ≤ -7% → 전량 매도 (예상 20주) · 최대 1회
 ※ 한 지시에서 나온 규칙은 한 묶음. 전량 매도가 실행되면 나머지 매도 규칙은 자동 종료
 [등록] [취소]
```
- 자연어를 정형 규칙(종목·조건·수량·횟수)으로 바꾼 뒤 **확인 카드로 보여 주고, 사용자가 버튼을 눌러야 등록**됩니다.
- 장중 20초마다 시세를 조회해 조건이 충족되면 안전 한도를 검사한 뒤 주문합니다.
- 조건 종류: 현재가 ≥/≤ 가격, 평균매입가 대비 수익률 ≥/≤ %. 수량은 주수 / 보유 대비 비율(매도) / 금액(매수)으로 정합니다.

### 2. 자동 투자: 맡길 돈
```
나: 자동 투자 1,000만 원, 3단계로 시작해 줘
장중대리: (성향 질문 6개) → 추천 3단계, 고른 단계와 일치

[자동 투자 제안 · 3단계(중립) · 1,000만 원]
국내 지수 ETF 40% · 미국 지수 ETF 20% · 채권 ETF 25% · 배당 ETF 15%
손실 한도: 전체 -10% 도달 시 매매 중단 후 확인 요청
리밸런싱: 매월 첫 거래일 10:00, 비중 ±5%p 벗어나면 (자동 실행)
구성: 3회 분할 매수 (거래일 09:30)
[승인] [단계 변경] [취소]
```

| 단계 | 성향 | 구성 | 손실 한도 |
|---|---|---|---|
| 1 | 안정 | 예금성·채권 ETF 80%, 지수 ETF 20% | -3% |
| 2 | 안정추구 | 채권 ETF 50%, 지수·배당 ETF 50% | -5% |
| 3 | 중립 | 지수 ETF 60%, 채권·배당 ETF 40% | -10% |
| 4 | 적극 | 지수 ETF 50%, 우량 대형주 50% | -15% |
| 5 | 공격 | 대형·성장주 70%, 섹터 ETF 30% | -20% |

종목과 비중은 [config/strategies.json](config/strategies.json)에 고정돼 있습니다 (후보 17종목, KIS 공식 종목 마스터로 코드·이름을 대조함). **LLM은 종목을 고르지 않습니다.**

### 3. 공통 업무
- 체결 알림: 근거, 판단 당시 시세, 체결가, 주문번호
- 매매일지: 한 줄에서 `근거 · 판단 시세 · 체결가 · 괴리(%)`를 대조할 수 있게 기록 (CSV, 설정하면 Google Sheets에도)
- 장 마감 요약 (15:40): `자동 투자 +0.8% · 규칙 매매 체결 1건 · 남은 규칙 3개`
- "멈춰" 한마디면 모든 규칙과 자동 투자를 즉시 중지 (LLM을 거치지 않고 코드가 바로 처리)
- **폭락일 손절 확인**: 시세 이상(예: 전일 대비 -16%)으로 종목 매매를 멈춘 동안에도 손절 규칙은 계속 감시합니다. 조건이 되면 자동으로 팔지 않고 **"그래도 팔까요?"** 카드를 보냅니다 ([그래도 매도] / [오늘은 보류], 30분 안에 답이 없으면 팔지 않고 다시 물음). 거래정지면 팔 수 없으므로 알림만 보냅니다.
- **알림 설정**: 체결·자동 투자·장 마감 요약·설정 변경·보고서 발송 알림을 각각 켜고 끕니다 (대시보드 설정 탭 또는 텔레그램 `/alerts 체결 off`). 끈 알림은 텔레그램으로 보내지 않고 대시보드 '대화·알림'에만 남습니다. 확인 카드, 안전 경고(전체 중지·시세 이상·손실 한도·API 오류), 주문 실패는 끌 수 없습니다.
- **PDF 보고서 발송**: 일간·주간·월간 중 받고 싶은 것을 고릅니다 (**셋 다 가능**). 받는 곳은 **메일 / 텔레그램 / 둘 다** 중에서 고릅니다. 장 마감 요약 뒤(기본 16:00) 그날 받을 보고서를 한 번에 보냅니다: 일간은 매 거래일, 주간은 그 주 마지막 거래일, 월간은 그 달 마지막 거래일. 메일은 PDF를 첨부한 한 통, 텔레그램은 PDF 파일로 옵니다. 텔레그램에서 `/report weekly`처럼 아무 때나 받을 수도 있습니다.

  | 장 | 내용 |
  |---|---|
  | 1장 · 핵심 요약 | 평가액·기간/누적 수익률·체결·규칙 타일, 평가액 추이(또는 목표 대비 비중) 차트, 핵심 요약 5줄, 확인할 일, 다음 일정 |
  | 2장 · 수익·자산 | 날짜별 평가액·수익률, 종목별 체결 요약, 자동 투자 구성(목표 대비), 직접 보유 종목 수익률 |
  | 3장~ · 세부 내역 | 주문 내역(근거·판단가·체결가·괴리), 안전 장치 기록, 규칙 현황, 주문 점검, 현재 안전 설정 |

  총 3~5장이며 5장을 넘으면 주문 표를 최근 건 위주로 줄이고, 전체 주문은 CSV로 함께 첨부합니다. 내용은 모두 DB 기록에서 만들고 LLM은 쓰지 않습니다.

### 4. 로컬 대시보드 (http://127.0.0.1:8765)
장중엔 텔레그램 알림만 보고, 퇴근 후나 주말에는 PC 브라우저로 한눈에 봅니다. 외부 라이브러리·CDN 없이 오프라인으로 동작합니다.

| 탭 | 보여 주는 것 |
|---|---|
| 개요 (수익 상태) | 계좌 총평가·현금, 자동 투자 누적/당일 수익률, 손실 한도까지 남은 여유, 오늘 주문·매수 한도 사용량, 평가액 추이 차트, 목표 대비 비중(허용 범위 ±5%p 표시), 직접 보유 종목 수익률 |
| 대화·알림 | 텔레그램과 같은 대화 기록. 확인 카드 버튼을 여기서 눌러도 됨 (텔레그램과 먼저 누른 쪽만 실행) |
| 규칙 | 감시 중/전체 규칙, 실행 횟수, 상태, 원문 |
| 매매일지 | 모든 주문의 근거 · 판단 시세 · 체결가 · 괴리, 전체 CSV 다운로드 |
| 보고서 | **PDF 보고서**(일간·주간·월간) 미리보기·다운로드·메일/텔레그램으로 보내기, 일일보고서 HTML/CSV, 일일 요약 누적 CSV |
| 설정 | 연결 상태와 점검 버튼(증권사·텔레그램 테스트 메시지·Google Sheets·테스트 메일), **연결 설정(.env) 편집**, **안전 한도·운영 일정·자동 투자·보고서·알림·휴장일 편집**, **설정 백업(다운로드)·복구(업로드)**(저장하면 바로 적용, 기본값으로 되돌리기), 시험용 수동 실행 |

상단에는 항상 브로커 모드, 장중/장외, 엔진 동작 시각, 전체 중지 상태와 **[멈춰]** 버튼이 보입니다. 국내 증권 관례대로 상승은 빨강 ▲, 하락은 파랑 ▼로 표시합니다.

**설정 편집의 안전장치**
- 화면에서 바꾼 값은 `data/settings.local.json`에만 저장되고(git 제외), `config/settings.json` 기본값은 그대로입니다.
- 기획안의 범위를 깨는 값은 서버가 거부합니다: 감시 주기 10~60초(초단타 금지·1분 내 주문), 하루 주문 최대 50회, 레버리지·인버스 키워드와 거래정지(58) 차단은 해제 불가, 장 시간 밖 매수 시각 불가.
- 안전 한도를 바꿀 때는 바뀌는 내용을 한 번 더 확인받고, 모든 설정 변경은 알림(텔레그램 포함)으로 기록됩니다.
- 앱키·토큰 같은 비밀값은 쓰기 전용입니다. 화면·알림·로그에 다시 나오지 않습니다. 증권사·텔레그램 토큰처럼 다시 시작해야 하는 항목은 ⟳로 표시합니다.

**휴대폰에서 보기** (`run --lan`)
- 하단 탭바, 표 → 카드 전환, 2열 타일, 하단 고정 입력창, 큰 터치 영역으로 모바일 화면에 맞췄습니다. 홈 화면에 추가하면 앱처럼 열립니다.
- `--lan`으로 실행하면 같은 Wi-Fi의 휴대폰에서 `http://<PC IP>:8765`로 접속합니다. 모든 요청에 **PIN 로그인**이 필요하고(5회 틀리면 5분 잠금), IP 주소로 들어온 요청만 받습니다.
- HTTP 평문이므로 집 Wi-Fi처럼 믿을 수 있는 네트워크에서만 쓰세요. 밖에서는 텔레그램을 쓰는 것이 전제입니다.

|---|---|---|

## 구조: LLM은 해석만, 주문은 코드가

```
텔레그램/웹/콘솔 ┬─ "멈춰", /명령 ─────────────► 코드가 즉시 처리
               └─ 자연어 ─► Claude Agent SDK ─► 조회 도구 / 확인 카드 생성 도구
                                                     │ (주문 도구 없음)
사용자 버튼 클릭 ─► PendingStore ─► 규칙 등록 · 자동투자 시작 · 한도 초과 승인
                                                     │
장중 엔진 (20초 주기, LLM 없음) ─► 규칙 평가 / 분할매수 / 리밸런싱 / 손실 한도
                                                     ▼
                     OrderGateway (모든 주문이 지나는 단 하나의 길)
                     중지 확인 → 금지 상품 → 보유 수량 → 안전 한도 → 주문 → 체결 확인
                                                     ▼
                    KIS 모의투자(또는 시뮬레이터) · 매매일지(CSV/Sheets) · 체결 알림
```

- **LLM에게 주문 도구를 주지 않습니다.** Claude는 정형 규칙 초안을 만들고 확인 카드를 띄우는 데까지만 합니다.
- Claude Code 내장 도구(Bash, 파일, 웹)는 모두 끄고(`tools=[]`), 허용 목록 밖 도구는 거부합니다(`permission_mode="dontAsk"`).
- 등록·변경·첫 구성·한도 초과·손실 한도 재개는 모두 **사용자의 버튼 클릭**으로만 확정됩니다. 버튼을 두 번 눌러도 한 번만 실행됩니다.

### 텔레그램 명령
명령어 외의 문장은 Claude가 해석합니다 (예: "하이닉스 7% 떨어지면 전부 팔아 줘"). 봇을 켜면 입력창의 `/` 메뉴에 아래 명령이 나타납니다.

| 명령 | 하는 일 |
|---|---|
| `멈춰` · `/stop` | 모든 매매 즉시 중지 (LLM을 거치지 않음) |
| `/resume` | 중지 해제 (확인 카드) |
| `/status` · `/rules` · `/portfolio` · `/journal` | 상태 · 감시 중 규칙 · 자동 투자 현황 · 최근 주문 5건 |
| `/report daily\|weekly\|monthly\|all [날짜]` | PDF 보고서를 텔레그램으로 받기 |
| `/alerts` · `/alerts 체결 off` | 알림 설정 보기 · 바꾸기 (체결·자동투자·요약·설정·보고서) |
| `/mode auto\|confirm` | 리밸런싱 자동 실행 / 매번 확인 |
| `/summary` · `/new` · `/help` | 지금 장 마감 요약 · 대화 초기화 · 사용법 |

## 범위
- 기본은 **모의투자** 계좌입니다. **실전 계좌**는 `.env`에 `BROKER=kis_real`과 `KIS_REAL_TRADING=yes`를 **둘 다** 넣어야 켜집니다. 하나만 있으면 실행을 멈추고, 웹 화면·설정 복구로는 실전으로 바꿀 수 없습니다. 실전에서는 등록한 규칙과 자동 투자가 **사용자 확인 없이** 실제 돈으로 체결됩니다 (규칙 등록·자동 투자 시작·안전 한도 초과 같은 확인 카드는 그대로).
- 국내 상장 주식·ETF만 다룹니다. 해외 직접투자, 선물·옵션, 레버리지·인버스는 다루지 않습니다.
- 초단타·고빈도 매매는 하지 않습니다 (20초 폴링, 하루 주문 20회 한도).
- 자동 투자는 미리 정한 전략과 후보 목록 안에서만 움직입니다.
